# DupeClient

**A lightweight Java networking library.**

DupeClient is an independent Java project focused on networking, connection management and packet handling.

## Features

- **RakNet:** Basic RakNet packet construction.
- **Proxy:** Proxy module foundation.
- **Lightweight:** Designed with simplicity and modularity in mind.
- **Java:** Written in pure Java.
- **Maven:** Distributed through JitPack.

## Installation

Add JitPack to your repositories:

```
repositories {
    maven { url 'https://jitpack.io' }
}
```

Add DupeClient as a dependency:

```
dependencies {
    implementation 'com.github.Azul991354:DupeClient:1.0.0'
}
```

## Package Structure

    com.dupeclient
    ├── Proxy.java
    └── RakNet.java

## Requirements

- Java 8 or newer.
- Maven or Gradle.
